# Lean Outliner

A small, fast outliner for Logseq-style Markdown notes, for Windows and Android.
Journals, `[[links]]`, `#tags`, `key:: value` properties, linked references, to-dos and quick capture,
on the same plain Markdown files Logseq uses.

Downloads: the public page https://github.com/srikanth-iyer/lean-outliner-releases (built automatically
on every change to main), or **Releases** here.
