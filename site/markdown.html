What is a Markdown note?

Try it

In brief: plain text with a few marks, kept in a file you own.

  • Plain text with a few marks

    • A Markdown note is an ordinary text file (its name ends in .md). A few simple marks in the text say how it should look: a # before a heading, a - before each point of a list, **stars** around bold words. An app such as thinky shows the marks as headings, bullets and bold; any text editor shows the same words as they are.

    • The file

      # Garden plan
- tomatoes by the fence
  - water **every morning**
- TODO buy seeds
- see [[Seed suppliers]] #garden

      In thinky

      Garden plan

      • tomatoes by the fence
        • water every morning
      • buy seeds
      • see Seed suppliers #garden

  • Why it's a good way to keep notes

    • Yours, for good. The notes are files in a folder on your own device. No account, and nothing is lost if an app goes away.

    • Any app can open them. Logseq, Obsidian, thinky, or a plain text editor: the same files work in all of them, so you can switch whenever you like.

    • Easy to sync and back up. They're small text files, so Google Drive, Syncthing or git keep them in step across your devices.

    • Readable even without an app. The marks are few and simple, so the text reads well on its own.

  • What Logseq-style adds

    • Logseq, and thinky, write every note as a point of an outline (a line starting with -), so notes can sit under other notes. They add a few marks of their own: [[Page name]] to link to a page, #tag, key:: value properties, TODO and DONE, and one file a day for the journal. It is still plain Markdown underneath.

    • Want to see it? Open the demo and write a few notes, or go back to the home page.
