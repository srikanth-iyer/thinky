  • Why I made it

    • I was an avid Logseq user. When Logseq decided to move away from Markdown files, I built my own, so I could keep working the way I loved and add the features I wanted along the way. thinky is inspired by Logseq and Obsidian: every note is a plain Markdown file in a folder you own.

    • thinky opens a folder of Logseq-style Markdown notes and lets you write in it: daily journals, pages, [[links]], #tags, properties, to-dos and the notes that link back to each page. It starts in a moment, stays small, and works on the same plain files Logseq uses, so you can switch back and forth.

      • Your notes stay plain Markdown files on your own devices. thinky has no accounts, no servers and no tracking. To use the same notes on your laptop and phone, keep the folder in a sync app you already use, such as Google Drive or Syncthing.

  • Get started

    • Start a new notes folder

      Notes

      pages a file per page

      journals a file per day

      2026_11_02.md

      logseq settings, backups

      assets pictures, files

      On first start, choose Create a new notes folder. thinky suggests a folder called "Notes" in your Documents (rename it or pick another place) and sets it up as shown. The Journals view starts on today's page, so you can just start writing.

      With Add the short tour (4 pages) ticked, it also adds four short pages, starting with Start here, that explain writing, links, the journal, to-dos and search on a computer and a phone. Delete them whenever you like.

    • Use it with your Logseq notes

      Logseq

      →

      your notes folder

      ←

      thinky

      Choose the folder that holds pages, journals and logseq/config.edn. Nothing is imported or converted: Logseq and thinky can use the same folder, even at the same time. When both change a page, thinky merges the two and never silently overwrites.

      • Your settings carry over. It reads that folder's config.edn: where journals and pages live, the date and file name formats, favourites, the to-do workflow, quick-capture templates and shortcuts.

      • Logseq's own Markdown. Bullets, key:: value properties, [[links]], #tags, block references, TODO/DONE, scheduled and deadline dates. Lines you didn't touch are written back exactly as they were, so Logseq opens every file thinky saves.

      • For Logseq's Markdown folders (Logseq 0.10 and its file-based graphs). Org-mode files, whiteboards and Logseq's newer database version aren't supported.

  • What it does

    Journals and pages

    Links, tags, properties, linked and unlinked references, and fast search that forgives typos in page names.

    Safe with sync

    If a page changed on another device while you were writing, thinky merges the two, or shows both side by side. Nothing is silently overwritten, and each page's history lets you go back.

    Quick capture

    Get a thought down without opening the app.

    Optional AI

    Tidy a note (Polish note), read a picture's words, ask about a page, or suggest links. Off until you choose a service in Settings › AI (what is sent):

    ClaudeOpenAIGeminiOpenRouterOllama, offline

    Backups

    On the laptop, only when something changed: dated zips of the notes folder, or a git repository such as GitHub.

    Feels like Logseq

    The same files, folders and settings, block references, templates, to-do states, tabs, two pages side by side, and many looks, light and dark.

    Lean

    About 3 MB to install on Windows, with no framework. Nothing runs in the background, except a tiny helper if you choose a shortcut key.

  • Installing

    • Windows: run the installer. Windows may show "Windows protected your PC", because the program isn't signed with a paid certificate; choose More info, then Run anyway (see the code signing policy). After that, thinky updates itself from Settings › About, and checks each update's signature before installing it.

    • Android: open the downloaded file and allow your browser to install apps when Android asks. thinky needs "access to all files" to read your notes folder. Later versions update from Settings › About.

    • Uninstalling: on Windows, Settings › Apps › Installed apps › thinky › Uninstall; on Android, like any app. Your notes folder is never touched.
